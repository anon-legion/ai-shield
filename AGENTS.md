# AGENTS.md

Browser extension: WXT + Svelte 5 + Tailwind 4. Package manager: Bun. Lint/format: Biome.

## Commands

- `bun install` — runs `wxt prepare` via postinstall (generates `.wxt/`).
- `bun run dev` / `bun run dev:firefox` — dev build, watch.
- `bun run build` / `bun run build:firefox` — production build to `.output/`.
- `bun run zip` / `bun run zip:firefox` — packaged extension zip.
- `bun run check` — typecheck via `svelte-check` (NOT `tsc`).
- `bunx biome check --write` — lint + format + organize imports.
- `bunx wxt prepare` — regenerate `.wxt/` (types, tsconfig, manifest types). Re-run after changing entrypoints, `wxt.config.ts`, or pulling.

No tests. No test command.

## Critical order

1. `bun install` (postinstall generates `.wxt/`).
2. `bunx wxt prepare` if entrypoints/manifest config changed.
3. `bunx biome check --write`.
4. `bun run check`.
5. `bun run build`.

Root `tsconfig.json` extends `.wxt/tsconfig.json` (generated, gitignored). `bun run check` fails if `.wxt/` missing — run `wxt prepare` first.

## Architecture

- WXT entrypoints live in `src/entrypoints/`, auto-discovered by filename:
  - `background.ts` — service worker.
  - `content.ts` — content script (currently matches `*.google.com`).
  - `popup/` — popup UI (Svelte app, entry HTML auto-generated).
- Manifest is auto-generated by WXT from `wxt.config.ts` + entrypoints. Do NOT hand-edit manifest or `.output/`.
- `.wxt/` and `.output/` are generated + gitignored. Never edit, never commit.
- Path aliases (from generated `.wxt/tsconfig.json`): `@`/`~` → `src`, `@@`/`~~` → repo root.
- Storage: IndexedDB via `idb`. DB name `ai-shield`, object store `redactions` (see `src/utils/constants.ts`).
- Messaging: `@webext-core/proxy-service` for background↔content/popup RPC. Reuse it; don't add parallel messaging layers.
- Icons: `src/assets/icon.svg` is the base; `@wxt-dev/auto-icons` generates sizes into `public/icon/`. Don't hand-edit generated icons.

## Conventions

- Svelte 5: use runes (`$state`, `$derived`, etc.) and `mount()` from `svelte`. Don't use legacy `new SvelteComponent` / `export let` props.
- Tailwind v4: configured via `@tailwindcss/vite` plugin + `@import "tailwindcss"` in `src/assets/tailwind.css`. No `tailwind.config` file by design.
- Biome: tabs for indent, single quotes, organize imports on. Formatter normalizes — run `biome format`/`check --write`, don't hand-argue style.
- Don't add new dependencies for storage/messaging/icon tooling — `idb`, `@webext-core/proxy-service`, `@wxt-dev/auto-icons` already cover it.
